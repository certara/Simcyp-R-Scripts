# Sensitivity Analysis Applications

In this folder you will find two examples scripts that run Global Sensitivity Analysis (GSA) using R packages with the Simcyp™ Simulator utilized as an ODE solver for a given parameter set and analysis handled entirely using R. The V26 Simcyp-R package is used to communicate with the Simulator.

## How to run each example

Navigate to the example folders and download all the files. Review README in example sub-folders.
